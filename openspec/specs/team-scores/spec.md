# Spec: Team Scores

## Purpose

为每支队伍提供得分输入框，得分与队伍配置一起持久化，并在页面右上角实时显示所有队伍的总分。

## Requirements

### Requirement: 每支队伍有独立得分输入框
系统 SHALL 在每行队伍中（角色槽位与备注框之间）提供一个标注为"得分 Score"的输入框，用于填写该队伍的得分。得分为非负整数，常见范围为 0–999999。得分数字 SHALL 以大号字体突出显示。

#### Scenario: 得分框随队伍出现且默认为 0
- **WHEN** 队伍行被渲染（初始加载或新增队伍），且该队伍尚未设置过得分
- **THEN** 该行显示标签为"得分 Score"的输入框，数值为 0

#### Scenario: 用户输入得分
- **WHEN** 用户在某支队伍的得分框中输入 123456
- **THEN** 得分框显示 123456，该队伍得分为 123456

#### Scenario: 只接受数字
- **WHEN** 用户在得分框中输入包含非数字字符的内容（如 "12a3-4"）
- **THEN** 非数字字符被忽略，得分框只保留数字（"1234"）

#### Scenario: 清空得分视为 0
- **WHEN** 用户清空得分框并移开焦点
- **THEN** 该队伍得分为 0，得分框显示 0

### Requirement: 得分自动持久化并跟随队伍
系统 SHALL 将每支队伍的得分与队伍配置一起保存到 localStorage。得分 SHALL 在队伍拖动排序时随队伍移动，在删除队伍时一并移除。

#### Scenario: 刷新页面后恢复得分
- **WHEN** 用户设置得分后刷新页面
- **THEN** 各队伍的得分框恢复显示之前设置的得分

#### Scenario: 排序时得分随队伍移动
- **WHEN** 队伍 1 得分为 100，队伍 2 得分为 200，用户将队伍 2 拖到队伍 1 之前
- **THEN** 新的第 1 支队伍得分为 200，第 2 支队伍得分为 100

#### Scenario: 删除队伍时移除得分
- **WHEN** 用户删除某支队伍
- **THEN** 该队伍的得分从 localStorage 中一并移除，其余队伍得分不变

#### Scenario: 旧存档兼容
- **WHEN** localStorage 中的存档不含得分数据
- **THEN** 页面正常加载，所有队伍得分为 0

### Requirement: 右上角显示总分
系统 SHALL 在页面右上角显示"总分 Total"标签，其数值为所有队伍得分之和，并在得分变更、新增或删除队伍时实时更新。系统 SHALL NOT 再在右上角显示"已获得"标签。

#### Scenario: 总分为各队得分之和
- **WHEN** 共有 3 支队伍，得分分别为 100、250、0
- **THEN** 右上角"总分 Total"显示 350

#### Scenario: 修改得分时总分实时更新
- **WHEN** 用户将某支队伍的得分从 100 改为 300
- **THEN** 总分立即增加 200，且得分框保持输入焦点

#### Scenario: 删除队伍后总分更新
- **WHEN** 用户删除一支得分为 250 的队伍
- **THEN** 总分立即减少 250

#### Scenario: 默认总分为 0
- **WHEN** 所有队伍得分均为 0 或没有队伍
- **THEN** 右上角"总分 Total"显示 0

#### Scenario: 不再显示已获得标签
- **WHEN** 页面加载
- **THEN** 右上角不显示"已获得"标签
