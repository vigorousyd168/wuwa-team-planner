## Why

用户在编排多支队伍时，难以一眼看出哪些角色已被放入某支队伍、哪些还未使用，容易造成重复放置或遗漏。通过在角色卡牌库中对"已被任意队伍使用的角色"进行视觉置灰，用户可以即时感知当前的占用状态。

## What Changes

- 角色卡牌库中，已被使用的角色卡牌显示置灰（降低亮度/透明度），与未使用角色形成视觉区别
- **普通角色**：出现在 ≥ 1 个槽位时置灰
- **生存治疗角色**（守岸人、莫宁、维里奈、卜灵、白芷）：出现在 ≥ 2 个槽位时才置灰，反映奶妈可跨队复用的实际游戏规则
- 当角色的使用次数降回阈值以下时，卡牌恢复正常显示
- 置灰状态随队伍配置的任何变更（放入、替换、移除、删除队伍）实时同步更新

## Capabilities

### New Capabilities

（无独立新能力，属于对现有卡牌库显示行为的增强）

### Modified Capabilities

- `character-roster`：角色卡牌库新增"已使用"视觉状态——普通角色使用 ≥ 1 次置灰，生存治疗角色使用 ≥ 2 次置灰，降回阈值后恢复

## Impact

- `index.html` / `generate.py`：在 `renderRoster()` 中计算当前已使用角色 ID 集合，为对应卡牌添加 CSS class；新增一条 CSS 规则控制置灰样式
- 无新依赖，无破坏性变更
